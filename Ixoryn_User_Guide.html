1. Introduction

Ixoryn is a cross-platform security intelligence platform that gives individuals and organizations world-class tools for cryptography, steganography, URL/domain threat analysis, and password security — all from a single unified interface.

Think of it as having four elite security tools — each independently battle-tested — working together seamlessly, sharing context and results, and presenting their combined intelligence through both a friendly guided interface and a professional command shell.

🔐
Cryptography
Encrypt files and messages, sign data, verify authenticity, generate keys, and hash anything using industry-best algorithms.
🕵️
Steganography
Forensically detect hidden data in images and audio, or covertly embed your own payloads using encryption and randomized embedding.
🌐
URL & Domain Audit
Expose phishing, homograph attacks, typosquatting, DNS poisoning, weak SSL, and malicious domains before they harm you.
🔑
Password & Hash Audit
Identify 300+ hash types, measure password entropy, estimate crack times, check compliance, and generate unbreakable passwords.
💡 Who is this for?

Ixoryn is designed for everyone — from a first-time user who has never opened a terminal, to an elite penetration tester running 500-target batch audits. Both users get the same powerful capabilities, just through different interfaces.

2. Installation

Prerequisites

The only thing you need installed before running Ixoryn is Python 3.9 or higher. Everything else is handled automatically.

ℹ️ No manual dependency setup

When you run Ixoryn for the first time, it will detect every missing package, show you what needs to be installed, and ask for your permission before installing anything. Just say Y and it handles the rest.

Option A — Git Clone (Recommended)

$ git clone https://github.com/ixoryn/ixoryn.git
$ cd ixoryn

Linux / Kali / macOS

$ chmod +x install.sh && ./install.sh
$ ixoryn

Windows

C:\ixoryn> install.bat
C:\ixoryn> python ixoryn.py

Direct Run (any OS)

$ python3 ixoryn.py

Option B — pip

$ pip install ixoryn
$ ixoryn
⚠️ Externally Managed Environment

On newer Linux systems (Ubuntu 23+, Debian 12+, Kali 2024+), Python may show an "externally-managed-environment" error when installing packages. Ixoryn automatically detects this and uses the --break-system-packages flag to bypass it. You do not need to create a virtual environment.

4. Operating Modes

Mode 1: Beginner Mode

Beginner Mode guides you through every action with numbered menus and clear prompts. You never need to remember commands. A built-in GUI file picker lets you browse your computer visually to select files — no typing file paths required.

Beginner Mode Menu ───────────────────────────── 1. Cryptography 2. Steganography 3. URL & Domain Auditing 4. Password & Hash Auditing 0. Back to Main Menu ───────────────────────────── Select module [1-4/0]: _

Everything is self-guided. For example, if you select Steganography → Operational Mode → Embed, Ixoryn will ask you: what file do you want to hide? → what file do you want to hide it in? → set a password? → where to save the output? All one step at a time.

Mode 2: Expert Mode

Expert Mode is a command shell modeled after tools like Metasploit. You type commands directly. This is significantly faster for advanced users and supports features like batch processing, JSON output, piping, and scripting.

ixoryn> help
ixoryn> help crypto
ixoryn> url audit suspicious.com -d deep
ixoryn> ti malicious-domain.xyz --json -o intel.json

Mode 3: Ixoryn Doctor

Ixoryn Doctor is a diagnostic tool. Run it anytime something feels wrong, or as a first step when deploying Ixoryn in a new environment.

It checks: Python version, all Python packages (with installed versions), system tools (ffmpeg, libmagic), network connectivity, file system health, then runs a quick self-test of every module. At the end it summarizes issues and can launch the full test suite.

5. Cryptography Module

The cryptography module handles encryption, decryption, digital signatures, key generation, and hashing. Every operation uses best-in-class algorithms chosen specifically because they are recommended by NIST, OWASP, and modern security standards.

ℹ️ Password Audit on Every Key Operation

Whenever you provide a password for encryption or key protection, Ixoryn automatically runs a strength audit and shows you the password's score, entropy, and estimated crack time before proceeding. If the password is weak, it warns you and asks for confirmation.

⛔ Wrong Password Behaviour

Ixoryn uses authenticated encryption (AES-256-GCM). If you provide the wrong password, decryption fails immediately with a clear error — it does not produce garbled output. There is no way to accidentally "partially decrypt" data.

Error message: "Decryption failed. Possible causes: wrong password, corrupted ciphertext, or tampered data."

6.2 Embedding (Hiding Data)

ℹ️ How the output format works

No matter what format your cover image is (JPG, BMP, GIF, WEBP, etc.), Ixoryn always saves the output as PNG — a lossless format. For audio, it always saves as FLAC. This is critical: lossy formats like JPEG destroy the hidden bits during re-compression, making extraction impossible.

ixoryn> stego embed -c family_photo.jpg -p secret_document.pdf -o stego_output.png -pass "HideMe@2024!"
[*] Embedding payload... [✓] Data successfully embedded! [✓] Output saved to: stego_output.png [*] Output is lossless PNG to prevent data corruption during transit.
FlagRequired?Description
-cYesCover file — the innocent-looking host file
-pYesPayload — the file you want to hide inside the cover
-oYesOutput path for the stego file
-passNoPassword — enables AES-256-GCM encryption AND randomized pixel embedding
💡 Always use a password

Without a password, payload bits are embedded in sequential pixel order — which is statistically detectable by tools like Ixoryn's own detector. With a password, Ixoryn uses a cryptographically seeded random traversal order (Xoshiro256**), making the embedding pattern indistinguishable from natural noise even under chi-square analysis.

6.3 Extraction (Revealing Hidden Data)

ixoryn> stego extract -f stego_output.png -pass "HideMe@2024!" -o recovered_document.pdf
[*] Extracting hidden data... [✓] Extraction successful! Payload name: secret_document.pdf [✓] Extracted payload saved to: recovered_document.pdf
⛔ Must use lossless stego file

You can only extract from PNG, BMP, WAV, or FLAC files. If you try to extract from a JPEG (even one that was originally a stego PNG but was converted), it will fail because JPEG compression destroys the hidden bits. Always preserve the original output file.

10. Report Generation

Every module in Ixoryn can export its results as a professional HTML or PDF report. These are formatted with a dark, modern design that is appropriate for organizational deliverables.

From Beginner Mode

After any audit, Ixoryn prompts: "Save report? [y/N/html/pdf]". Type html or pdf and it generates immediately.

From Expert Mode

ixoryn> url audit target.com -d deep --json -o audit.json
ixoryn> report html url audit.json -o target_report.html
[✓] Report saved to: target_report.html
ixoryn> ti malware-site.xyz --json -o intel.json
ixoryn> report pdf threat_intel intel.json -o intel_report.pdf
[✓] Report saved to: intel_report.pdf
⚠️ PDF generation requirements

PDF export requires either weasyprint (install: pip install weasyprint) or wkhtmltopdf + pdfkit. If neither is available, Ixoryn saves HTML instead and notifies you. HTML reports open in any browser and can be printed to PDF from there.

11. Setting Up API Keys

Add API keys to ~/.ixoryn/config.json (created automatically on first run):

{
  "version": "1.0.0",
  "api_keys": {
    "virustotal": "YOUR_VIRUSTOTAL_KEY",
    "abuseipdb": "YOUR_ABUSEIPDB_KEY",
    "google_safe_browsing": "YOUR_GSB_KEY",
    "shodan": "YOUR_SHODAN_KEY",
    "otx": "YOUR_OTX_KEY"
  }
}

Alternatively, set environment variables (these take priority over the config file):

$ export VIRUSTOTAL_API_KEY="your_key_here"
$ export ABUSEIPDB_API_KEY="your_key_here"
$ export GSB_API_KEY="your_key_here"
$ export SHODAN_API_KEY="your_key_here"
$ export OTX_API_KEY="your_key_here"

All of these services have free registration tiers. No payment is required to get started.

18. Technology Choices (Technical)

Every technology decision in Ixoryn was deliberate. Here is the rationale for each critical choice, including why alternatives were rejected:

ComponentIxoryn UsesAlternatives RejectedWhy This Choice
Key Derivation Argon2id PBKDF2, scrypt, bcrypt Argon2id won the Password Hashing Competition (2015). It is both memory-hard (defeats GPU/ASIC attacks) and resistant to side-channel attacks. PBKDF2 has no memory hardness. scrypt has implementation vulnerabilities. bcrypt has a 72-byte password limit and is slower to configure correctly.
Symmetric Encryption AES-256-GCM AES-CBC, ChaCha20, DES, 3DES AES-GCM provides authenticated encryption — it simultaneously encrypts AND verifies integrity in one operation. AES-CBC requires separate MAC and is vulnerable to padding oracle attacks. DES/3DES are broken. ChaCha20-Poly1305 is an excellent alternative (used in NaCl module) but AES-GCM has hardware acceleration on all modern CPUs.
Digital Signatures Ed25519 RSA-2048, ECDSA (P-256) Ed25519 uses Curve25519 which is immune to timing attacks by design — other curves leak private key bits through timing. Ed25519 has smaller keys (32 bytes vs. 256+ for RSA), faster operations, and is resistant to weak RNG attacks that break ECDSA.
Asymmetric Encryption NaCl Box (X25519 + XSalsa20-Poly1305) RSA-OAEP, ElGamal NaCl was designed by Daniel Bernstein specifically to be impossible to use insecurely. The API makes correct usage the only option. RSA-OAEP requires careful padding selection. NaCl performs key exchange and encryption in a single, audited primitive.
Hashing (fast) BLAKE2b MD5, SHA-1, SHA-256 BLAKE2b is faster than MD5 on 64-bit systems, cryptographically secure (unlike MD5/SHA-1 which are broken), and is recommended by NIST. SHA-256 is also offered for compatibility.
Stego Embedding LSB + Xoshiro256** PRNG DCT, F5, OutGuess LSB with randomized traversal provides the best capacity-to-detectability ratio for general use. DCT-based tools are JPEG-specific and have lower capacity. F5 and OutGuess are harder to implement cross-format. The randomized traversal specifically neutralizes chi-square attacks against Ixoryn's own outputs.
Stego Detection Multi-method ensemble + Random Forest Single-test tools (StegHide detect only) No single test is reliable across all stego methods. Chi-square detects sequential LSB; RS analysis detects LSB with modifications; ELA detects JPEG manipulation; ML generalizes across methods. The ensemble provides much higher accuracy than any single technique.
Password Scoring zxcvbn Naive rules (length + charset counts) zxcvbn was developed by Dropbox and uses a realistic attacker model — it checks dictionary words, common patterns, dates, keyboard walks, and leet substitutions. Naive rules would give "P@ssw0rd!" a high score despite being trivially crackable. zxcvbn gives it 1/4.
PRNG for traversal Xoshiro256** Python random, numpy random Xoshiro256** passes all statistical randomness tests (BigCrush), is fast, and is fully deterministic from seed — allowing exact traversal reproduction during extraction. Python's random module uses Mersenne Twister which has predictable patterns that could theoretically reveal traversal order.
